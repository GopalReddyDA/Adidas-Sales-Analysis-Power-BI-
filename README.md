## Adidas Sales Analysis | Power BI

A Power BI dashboard project analyzing Adidas US Sales data to uncover sales trends, regional performance, product insights, and retailer performance through interactive visualizations.

## Project Overview :
This project demonstrates an end-to-end sales analysis workflow using Power BI. It covers data preparation, KPI creation, interactive dashboards, and business intelligence reporting using the Adidas US Sales dataset.

## Features : 
* Data Preparation
* Imported Adidas US Sales dataset from Excel.
* Used a pre-cleaned dataset for analysis.
* Verified data types and prepared the dataset for reporting.
* Key Performance Indicators (KPIs)

## The dashboard includes the following KPIs:
* Total Sales
* Operating Profit
* Units Sold
* Average Price per Unit
* Average Margin

## Dashboard Visualizations :
## Sales Trend Analysis
* Area Chart displaying monthly sales trends.
* Helps identify seasonal patterns and peak sales periods.
## Sales by State
* Shape Map visualizing sales performance across the United States.
## Sales by Region
* Donut Chart showing regional contribution to total sales.
## Sales by Product
* Bar Chart comparing sales across different product categories.
## Sales by Retailer
* Bar Chart highlighting sales performance by retailer.

## Interactive Dashboard :
* Region slicer
* Invoice Date slicer
* Cross-filtering between visuals
* Interactive drill-down analysis

## Business Insights :
* Monitor overall sales performance.
* Compare profitability across regions.
* Identify top-performing products.
* Evaluate retailer performance.
* Discover seasonal sales trends.
* Analyze geographic sales distribution.
